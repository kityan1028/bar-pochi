# BAR POCHI ホームページ

すすきの「BAR POCHI」の公式サイト一式です。HTML / CSS / JavaScript だけで動くので、GitHub Pages・Firebase Hosting のどちらにもそのまま置けます。

※ `.claude` フォルダは作業用です。公開時にアップロードする必要はありません。

### 確認するときの注意

HTML ファイルをダブルクリックやプレビューで直接開くと、デザインや動きが読み込まれず崩れて見えることがあります。
手元で確認するときは、このフォルダで次のコマンドを実行し、ブラウザで `http://localhost:8000` を開いてください。

```bash
python3 -m http.server 8000
```

## 1. GitHub Pages で公開する（まずはこちら）

1. GitHub にログインし、右上の「＋」→「New repository」でリポジトリを作成（例：`bar-pochi`、Public）。
2. 作成したリポジトリで「Add file」→「Upload files」を開き、このフォルダの中身をすべてドラッグ＆ドロップ。
   - Mac で `.nojekyll` が見えない場合は、Finder で `command + shift + .` を押すと表示されます。
   - `.claude` フォルダはアップロード不要です。
3. 「Commit changes」を押す。
4. リポジトリの「Settings」→「Pages」→「Branch」を `main`、フォルダを `/ (root)` にして「Save」。
5. 数分後、`https://<GitHubのユーザー名>.github.io/bar-pochi/` で公開されます。

## 2. Firebase Hosting で公開する（あとで切り替える場合）

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作成し、プロジェクトID を控える。
2. パソコンに Node.js を入れたうえで、ターミナルで以下を実行：
   ```bash
   npm install -g firebase-tools
   firebase login
   ```
3. このフォルダに移動して公開：
   ```bash
   firebase deploy --only hosting --project <プロジェクトID>
   ```
4. `https://<プロジェクトID>.web.app` で公開されます。

## 3. 予約フォームの有効化（最初の1回だけ）

予約フォームは [FormSubmit](https://formsubmit.co/) を使って `sz7.hahahahani@gmail.com` にメールを送ります。

1. サイトを公開したあと、予約フォームから一度テスト送信する。
   （パソコンでファイルを直接開いた状態では送信できません。公開後のURLで試してください）
   **この1回目は画面に「現在フォームの準備中のため送信できませんでした」と表示されますが、正常です。**
2. `sz7.hahahahani@gmail.com` に FormSubmit から「Activate Form」の確認メールが届くので、ボタンを押して有効化する。
3. もう一度テスト送信し、「送信が完了しました」の画面になること、表形式のメールが届くことを確認する。
   件名は「【BAR POCHI】ご予約リクエスト 日付 お名前様」です。

※ GitHub Pages から Firebase に引っ越したとき（サイトのアドレスが変わったとき）は、もう一度この有効化が必要になる場合があります。

**おすすめ（迷惑メール対策）**：有効化すると、メールアドレスの代わりに使えるランダムな文字列が FormSubmit から届きます。
`assets/js/reserve.js` の `ENDPOINT` と、`reserve.html` の `<form action="...">` にある `sz7.hahahahani@gmail.com` をその文字列に置き換えると、ページ上にメールアドレスが載らなくなります。

- 来店日に **木曜日** を選ぶと「お食事（ご飯）のご希望：希望する／希望しない」が表示され、必須になります。
- 来店日に **日曜日** を選ぶと「日曜日は定休日ですが、ご相談により営業いたします」と案内が出ます。
- 貸切ページの「予約フォームで相談する」から来ると、席の希望が「貸切のご相談」に自動で選ばれます。

## 6. 木曜ごはんの写真

`thursday.html` では、3枚の写真が1つの額の中で約6秒ごとにゆっくり入れ替わります（案C「灯りのスライド」）。下に小さな写真3枚が目次として並びます。

| ファイル | 料理名（写真の左下と、目次の下に表示） |
| --- | --- |
| `assets/img/thursday-1.jpg` | 夏野菜のバターチキンカレー |
| `assets/img/thursday-2.jpg` | 牛肉のたたきとブロッコリーの唐揚げ |
| `assets/img/thursday-3.jpg` | カレイの塩焼き |

- 写真を入れ替えるときは、同じファイル名で上書きしてください（大きい写真と目次の2か所が、まとめて変わります）。
  横長（だいたい 3:2）で、料理が額いっぱいに写るくらい寄った写真がきれいに収まります。
- カレーの写真は、ほかの2枚と同じ大きさで見えるよう、器に寄って切り出したものです（元の写真は `assets/img/originals/thursday-1.jpg`）。
  元の写真が小さめ（横480ピクセル）なので少しやわらかく見えます。大きい元写真があれば、差し替えるとよりくっきりします。
- 料理名を変えるときは、`thursday.html` の料理名（日本語・英語）と、写真の説明文（`alt` と `data-en-alt`）を書き換えてください。

## 7. カラオケ・ダーツの画像について

`assets/img/karaoke.jpg`・`darts.jpg` は AI（GPT Image 2.5）で生成したイメージ画像です。サイト上には「※画像はイメージです」と表示しています。
実際のお店の写真が撮れたら、同じファイル名で差し替えてください。

住所・営業時間・席数・アクセスなどのお店の情報は、すべて正式な内容になりました（点線の下線はもうありません）。

  （キャッチコピーは決定済み：トップ「すすきのの足もとに、ひそやかな夜。」、ページ下「今夜すすきのの足元に、ひそかな夜を。」）

## 9. 言語切り替え（日本語 / English）

ヘッダーの「JA / EN」で切り替わります。選んだ言語はブラウザに記憶されます。
文章は `<span lang="ja">日本語</span><span lang="en">English</span>` のように 2 つ並べて書いてあり、選んだ言語だけが表示されます。文章を直すときは両方を書き換えてください。
